# Start a project

Use [the setup guide](../../prompts/setup_aosdf.md) with [workflow_initiator](../../workflow_initiator.md). Work in a project-owned workspace; the public framework remains a reusable source.

```text
sample-product/                     # Application repository
sample-product-Documents/           # Project documentation repository
  docs/
    project_status.md
    identified_gaps.md
    documents/
      00_Introduction/
      01_Project_Definition/
      02_Requirements/
      03_System_Design/
      04_Security_and_Compliance/
      05_AI_Agent_System/
      06_Execution_Plan/
      07_Milestones/
```

The setup guide defines the complete section names and optional sections; this is an orientation sketch. Fill the product definition, requirements, architecture and security constraints before Captain planning. Pick Strategy A or coordinated Strategy B explicitly. For coordination, choose the process Mode, thread identities, ownership, model policy, environment and budget before creating empty runtime records. See [the synthetic walkthrough](../coordinated-development/README.md).
