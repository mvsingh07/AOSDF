# AOSDF 3.8.0 — outcome-first delivery and founder visibility

This release adapts update5 from its 20 registry-selected frozen payloads, verified by SHA-256. It merges rules by meaning into the root's existing generic sections and preserves C16/C17 numbering without importing the source product's environment policy.

Included: single implementation review, strict outcome-first acceptance and deferral discipline, result `deferred`/`new_files` fields, founder decisions and hourly reminders, non-blocking learning/research, generated human-actions, Summary lines, budget/owner-health alerts, a 96-wake cap, quiet-channel rotation and history-aware old-round lookup. Templates are empty, metadata-bearing, and receive fresh identities on project instantiation.

The generic bounded-job adapter remains launch-disabled; only archived-round lookup was merged. No local account/profile selection, separate sprint controller, product proposals/review history, channel/history/run state, live inbox or existing deferred items are distributed. All automation remains inactive.

Use [the migration guide](migrate.md), [adaptation map](source-adaptations.json), and [source inventory](inventory.json). Earlier release inventories remain immutable historical snapshots. Local acceptance is not a commit, package publication, live owner wake or another project's migration.
