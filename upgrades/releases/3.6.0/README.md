# 3.6.0 distribution scope

The reusable framework baseline covers:

- 3.4: opt-in coordination, architect/coordinator/worker boundaries, proportional Strategy B, four process Modes, inactive dispatch and reconciliation support.
- 3.5: inactive bounded file notifications with explicit target configuration and separate observer/receiver behavior.
- 3.6: native Markdown metadata authoring, creation helper, fixed legacy compatibility and a MkDocs validation gate.

Use [the migration recipe](migrate.md) against the source files listed in `inventory.json`. No private originating workspace, live product topology, active runner profile, authorization grant or per-product receipt is required or transferred. This source snapshot includes subsequent repository packaging; it does not claim a new framework release or activation.
