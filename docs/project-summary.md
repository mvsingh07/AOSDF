# AOSDF project summary

AOSDF (AI-Orchestrated Software Development Framework) provides the foundations of an AI-orchestrated software factory. It translates product requirements and architecture into traceable execution plans, coordinates specialized AI agents through explicit ownership and durable task state, and applies risk-based review and evidence-based validation. Public tooling includes an MCP server, VS Code integration, documentation tools and reusable coordination templates. A separate private Next.js/Supabase service provides GitHub-connected documentation builds, deployment and role-based sharing.

The framework is not presented as a proven fully autonomous production system. Reusable automation is inactive by default; real runner integration and environment acceptance remain project responsibilities. Demonstrating repeatable specification-to-release delivery across independent applications, including failure recovery and measured human intervention, is the next software-factory milestone.
